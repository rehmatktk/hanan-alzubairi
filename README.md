# Hanan Alzubairi — Heritage Documentation Portfolio

Portfolio of Hanan Mahfoodh Abdulwadod Alzubairi — BA Islamic Archaeology,
Sana'a University (ranked first in class, 2024).

Fieldwork and conservation across the Great Mosque of Al-Rawdah survey,
manuscript conservation at Dar al-Makhtutat, carved gypsum (jiṣṣ) workshop
practice, measured pottery drawing, and museum documentation.

## Contents

`index.html` — the complete portfolio. Fully self-contained: every photograph is
embedded in the file, so it runs from any web host, a USB stick, or an email
attachment with no other files required.

## Publishing on GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: **main** / **root** → Save.
The site appears at the URL GitHub shows on that page within a minute or two.

`.nojekyll` is included so Pages serves the file as-is.
